# AI Browser Copilot

An AI-powered Chrome Extension that allows users to interact with websites using natural language commands.

## Vision

Build a browser assistant that can understand webpages, analyze websites, and execute user-requested browser tasks using AI.

## Architecture

```
Chrome Extension
      |
      |
AI Provider Layer
      |
      |
Browser Understanding Engine
      |
      |
Browser Actions
```

## AI Provider Support

- Google Gemini API
- OpenAI GPT API
- Custom AI API

## Core Features

- Sidebar AI chat
- Current page understanding
- Website analysis
- Website feature extraction
- Design analysis
- Browser actions
- Form assistance
- Research assistant
- AI-powered workflow execution
